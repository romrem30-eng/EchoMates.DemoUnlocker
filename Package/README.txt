========================================================================
   ECHO MATES DEMO - FULL GAME UNLOCKER & SANDBOX MOD (v1.2.0)
========================================================================

[EN] QUICK INSTALLATION:
1. Extract this entire zip archive to any folder.
2. Double-click "INSTALL.bat".
3. The installer will automatically find your game folder in Steam and install the mod.
4. Launch "Echo Mates Demo" from Steam and enjoy!

[EN] AUTO-UPDATES:
Whenever a new mod update is released, simply double-click "UPDATE.bat".
It will automatically connect to GitHub, download the latest DemoUnlockerMod.dll,
and replace it in your game folder in seconds.

[EN] MANUAL INSTALLATION (OPTIONAL):
If you prefer manual install, simply copy everything inside the "files" folder 
directly into your "Echo Mates Demo" game root directory.

------------------------------------------------------------------------
WHAT THIS MOD DOES:
------------------------------------------------------------------------
- Unlocks Campaign Depth up to Floor 99 (Endless Descent without 10-floor cap).
- Unlocks all Base Buildings, Research, Blueprints, Chips & Gear.
- Completely blocks game telemetry (Stealth mode - no data sent to devs).
- Optional Dev Spawn Menu: Press F1 (disabled by default in config).
- Optional Troll Exorcist 180 Neck: Press X (disabled by default in config).

------------------------------------------------------------------------
CONFIGURATION:
------------------------------------------------------------------------
To change mod settings, open this file with Notepad:
  <Game Directory>\BepInEx\config\com.modder.echomates.sandbox.cfg

Options available:
- UnlockDemoLimits = true/false
- MaxCampaignDepth = 99 (or any number)
- BlockTelemetry = true/false
- EnableDevMenu = false/true  (F1 dev spawn catalog)
- EnableExorcistNeck = false/true (X 180 head rotation)
- ShowWatermark = false/true  (green status text on screen)

------------------------------------------------------------------------
HOW TO UNINSTALL:
------------------------------------------------------------------------
Simply run "UNINSTALL.bat". It will cleanly remove all mod files and restore
your original demo without affecting your saves.
