# Echo Mates Demo - Full Game Limits Unlocker & Sandbox Mod

A comprehensive BepInEx 5 mod and endless descent progression system for **Echo Mates Demo**.

## Features
- **Endless Campaign Descent**: Removes the 10-floor demo wall (LevelTypes.MaxDepth raised up to Floor 99).
- **All Blueprints & Gear Unlocked**: Full access to base crafting stations, research tables, chips, and structures.
- **Stealth Mode (Telemetry Blocker)**: Completely disables backend analytics and metrics sent to game developers.
- **Auto-Updater System**: Includes a dedicated UPDATE.bat that automatically checks and pulls the latest DLL releases from GitHub in seconds.
- **Optional Dev Menu**: Developer spawn catalog available on F1 (toggleable in config).
- **Optional Exorcist Neck Mode**: 180-degree neck twist on X (toggleable in config).

## Installation
1. Download the latest EchoMates_Full_Unlocker_vX.X.X.zip from [Releases](https://github.com/romrem30-eng/EchoMates.DemoUnlocker/releases).
2. Extract the archive anywhere.
3. Double-click INSTALL.bat. The installer will automatically locate your Steam installation and install the mod.

## Updating
Whenever a new release is available, simply double-click UPDATE.bat.
